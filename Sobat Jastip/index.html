Dari Kota Asal A : Format & Tarif

Via Udara

  • Tarif Rp50/gram (contoh), tanpa minimal berat
  • Estimasi pengiriman 3–5 hari (contoh)
✅ Format Pengiriman:
Penerima Demo A (Nama pelanggan) Alamat: Jl. Contoh No. 1, Kelurahan Demo, Kota Asal A, 00000 Telepon contoh: 08xx-xxxx-0001

Via Laut

  • Tarif Rp10.000/kg (contoh), min 1kg
  • Dikenakan kubikasi bila paket besar tp ringan
✅ Format Pengiriman:
Penerima Demo A — Laut (Nama pelanggan) Alamat: Jl. Ilustrasi No. 2, Kelurahan Demo, Kota Asal A, 00000 Telepon contoh: 08xx-xxxx-0002
Dari Kota Asal B : Format & Tarif

Via Udara

  • Tarif Rp60/gram (contoh), tanpa minimal berat
✅ Format Pengiriman:
Penerima Demo B (Nama pelanggan) Alamat: Jl. Sampel No. 3, Kelurahan Demo, Kota Asal B, 00000 Telepon contoh: 08xx-xxxx-0003

Via Laut

  • Tarif Rp12.000/kg atau Rp800.000/m³ (contoh), min 1kg
  • Dikenakan kubikasi jika paket besar tp ringan
✅ Format Pengiriman:
Penerima Demo B — Laut (Nama pelanggan) Alamat: Jl. Simulasi No. 4, Kelurahan Demo, Kota Asal B, 00000 Telepon contoh: 08xx-xxxx-0004
