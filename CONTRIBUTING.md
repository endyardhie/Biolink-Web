# Kontribusi ke Biolink-Web

Terima kasih telah membantu memperluas koleksi template biolink yang gratis digunakan semua orang.

## Menambahkan template

1. Fork repo dan buat branch untuk perubahan Anda.
2. Buat satu folder baru menggunakan huruf kecil dan tanda hubung, misalnya `toko-bunga/`. Jangan menimpa template lain.
3. Sertakan `index.html`, aset lokal yang diperlukan, `README.md`, `preview.jpg` atau `preview.png`, dan salinan lisensi MIT repo.
4. Tulis petunjuk penggunaan, bagian yang perlu diganti, kebutuhan dependensi jika ada, serta informasi demo.
5. Tambahkan template ke tabel koleksi pada README utama.
6. Ajukan pull request berisi deskripsi template dan hasil pemeriksaan.

## Pedoman

- Utamakan HTML/CSS/JavaScript yang dapat digunakan tanpa proses build. Setiap folder harus mandiri; jangan mengandalkan aset template lain.
- Gunakan data contoh dan tandai sebagai demo. Jangan sertakan data pribadi, kredensial, atau token.
- Gunakan aset buatan sendiri atau aset dengan izin redistribusi yang sesuai; sertakan atribusi yang diwajibkan.
- Jangan menambahkan pelacak, iklan, atau permintaan jaringan tersembunyi.
- Jaga dukungan perangkat seluler, navigasi keyboard, fokus yang terlihat, dan kontras yang mudah dibaca.
- Periksa tautan, tombol, dialog, FAQ, serta tampilan pada layar sempit dan desktop sebelum mengajukan perubahan.
- Kontribusi kode menggunakan lisensi MIT repo; jelaskan lisensi aset pihak ketiga jika ada.

Untuk memperbaiki template yang sudah ada, jelaskan masalah dan hasil setelah perbaikannya. Sertakan gambar jika tampilan berubah.
